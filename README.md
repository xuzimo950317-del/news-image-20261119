The world news of Thursday 19 November 2026 on one page: the first Trump-Xi-Putin trilateral summit in Shenzhen, the World Court's Rohingya ruling, COP31, burning tankers near Hormuz, Ukraine's strike on the Crimean Bridge, Bangladesh unrest, sliding markets, a record Van Gogh, Voyager 1 at one light-day and more. A pure-Python program draws the whole front page pixel by pixel with its own 5x7 bitmap font and writes it as a PNG - no image files, no libraries, the same bytes every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
